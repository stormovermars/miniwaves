Installing or upgrading mw now also installs or updates the Claude Code plugins.

- `install.sh`, `install.ps1` and `mw update` (after a real update) install or update the `mw` and `tidewatch` plugins from the miniwaves marketplace when `claude` is on PATH. It is best effort: a failed plugin step never fails the install or changes the exit status.
- `MW_NO_PLUGINS=1` skips the plugin step. `mw update --plugins` runs only that step.
- After installing, run `/tidewatch`, then `/tidewatch add PATH`.
- Upgrading from 0.3.2 or older: the old `mw` does not know the plugin step, so after `mw update` run `mw update --plugins` once (or re-run `install.sh` / `install.ps1`).
- tidewatch: one `Fanfare: off|all|<set>` button in the top row cycles off, all, each fanfare set, then off on every press (like `Auto:`); `/tidewatch fanfare next` does the same. The footer Fanfare and Set buttons are removed; Test stays.
