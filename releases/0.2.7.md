Fanfare change; no schema change, no migration.

- The default finale length is 60 s (was 300); the cap stays 3600. Boards that saved `finale_seconds=300` (any `mw fanfare set` on 0.2.4–0.2.6 saved it) keep it: run `mw fanfare set finale_seconds=60`.
- The finale shows a Stop dialog (macOS `osascript`, Windows popup, Linux `zenity` when installed) that times out with the clip and kills the player on Stop. `mw fanfare set stop_dialog=false` turns it off; the milestone never shows one. `mw fanfare stop` also closes the dialog.
