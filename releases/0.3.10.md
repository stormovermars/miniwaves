After `mw update`, run `mw update --plugins` once: the mw-jobs plugin changes shape and the tidewatch plugin is retired. See MIGRATION.md (0.3.10) for the per-job news folder and the removed user keys.

mw-jobs: Markdown instead of panes

- TSK-074: the live jobs/news panes are gone. `/mw-jobs` opens `jobs.md` (`mw board --md`): what runs now, needs you, review, ready, recently done, milestones. `/mw-news` opens the news edition. `/mw-publish` publishes both as one private claude.ai page and starts the next edition. A quiet hook refreshes `jobs.md` after mw commands that change the board.
- News is a tabloid-style Markdown edition since the last published one: lead story, also in this edition, needs you, proof (images, release notes), coming up. `--format text` keeps the 70-column bulletin.
- Status bar: `mw status --line [--link]` prints `mw:N2R1B1:12/40` (N needs you, R review, B blocked on another item, open/all without drafts). Set `"statusLine": {"type": "command", "command": "mw status --line --link"}` in `~/.claude/settings.json`. `/mw-status` (`mw status --explain`) explains it with versions and settings.
- `mw block --on ID` records a block on another item; a block without it counts as needing you.
- `mw fanfare on|off`.
- Each job's news defaults to its own folder `docs/news/<job>/`.
- Removed: the pane.*, alerts.* (except alerts.on/exec) and status.detail user keys, the job keys pane and pane.style, /mw-watch, /mw-configure and the tidewatch plugin. Old stored values are ignored.
