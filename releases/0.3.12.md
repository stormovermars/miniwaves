No schema change, no migration step. 0.3.11 was never published; its change ships here.

- TSK-075: `mw status --line` outside a board (e.g. `~/apps`) sums the boards up to two folders below, e.g. `mw:N5:16/575`. The total is cached for 30 seconds; the link is added only when exactly one board is found.
- TSK-076: an item blocked `--on X` goes back to ready when X is final (`done` with the judge gate off, `accept`, or `wave close`), so it no longer counts as "needs you". `mw block --on` an item that is already done is refused.
- TSK-077: `mw board --md`, jobs.md and `mw board --html` show a Waiting group with "waits on ID (title)", separate from Needs you.
- CHR-016/017/018: prompt lines. The planner proposes "Out of scope: …" decisions for a human to record; sessions check for an existing implementation and reproduce bugs first, and write blocks/asks as "Settled: … Open: …"; one item = one fresh session, with wide refactors as expand → migrate → contract.
