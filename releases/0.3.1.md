Migration fix; no schema change.

- `mw migrate` failed on boards written by 0.2.x that have archived tenants (`json: cannot unmarshal bool into Go struct field Tenant.tenants.archived of type int`), so 0.3.0 could neither read nor migrate them. It now reads the schema first and loads schema 8 and 9 indexes through the normal loader; archived tenants stay archived and keep their items. Upgrade to 0.3.1 and run `mw migrate`; the board is untouched until then.
