**Upgrading from 0.3.2 or 0.3.3: after `mw update`, run `mw update --plugins` once.** The old binary updates its old plugin list, so only the new one installs `mw-jobs` and removes the retired plugins. (Re-running the install one-liner works too.)

New commands

- `mw boards [DIR] [--depth N] [--up] [-j]` finds boards and their tenants, read-only. Depth is 1..6 (default: your `discover.depth`, 4). It stops at 200 boards or 5 s. An index file over 1 MB is reported as an error, Windows skips AppData, and on macOS `--up` does not stat ancestors inside protected folders (Documents, Desktop, Downloads, Library and so on) unless it starts inside one. `-j`: `{"root","boards":[{"dir","path","name","schema","tenants":[{"slug","name","archived"}],"error"?}],"truncated","reason"}`.
- `mw configure` walks your personal settings (Pane, Alerts, Fanfare, Chat bar, Discovery) and ends with Save or Discard. `mw configure --show [-j]` prints them; `mw configure KEY=VALUE...` saves without prompting; with no terminal it prints the settings and a hint.
- `mw user get [KEY] [-j]` lists every key with its value, default and source (`default`, `user`, or `board`), group and choices. Keys: `pane.refresh` (15s, 30s, 1m, 5m, off), `pane.style`, `pane.zoom` (-2..2), `pane.fit` (80, fill), `pane.open` (jobs, news), `alerts.enabled`, `alerts.kinds` (any of new, blocked, ask, review, done, release, metrics; or `all`; or `none`), `alerts.message`, `alerts.sound`, `fanfare.enabled`, `fanfare.use`, `status.show`, `status.detail` (compact, full), `discover.home`, `discover.depth` (1..6).
- `mw news --full` lifts the row caps (every `more` is 0). The json gets `full: true` and `trimmed_rows`. It works only with `-o FILE`, `-o -` (stdout), `--format json` or `--format text`, and never rewrites the desk's `status.md` draft. `--full --release` is refused.
- Writes to the user config are locked, so concurrent `mw user set` and `mw configure` lose nothing.

Fanfare

- `install.sh`, `install.ps1`, `mw update` and `mw update --plugins` run `mw user fanfare-defaults`, which sets `fanfare.enabled=true` and `fanfare.use=all` only where they are unset. `MW_NO_FANFARE=1` or `MW_NO_PLUGINS=1` skips it.
- A board that explicitly runs `mw fanfare set enabled=false` wins over the user layer (`mw user get` shows source `board`). `mw fanfare use NAME` no longer counts as a board decision.
- With no fanfare songs on disk a built-in fanfare plays. `scripts/gen_fanfare_default.py` generates it; it is cached in the user cache dir.

Plugins

- `mw-watch` (formerly `tidewatch`) is retired. **mw-jobs** is the only pane plugin: `/mw jobs`, `/mw news`, `/mw-configure`, and `/mw fanfare` for stop and test. It needs no setup: it finds your boards with `mw boards`.
- `install.sh`, `install.ps1` and `mw update` / `mw update --plugins` install `mw` and `mw-jobs` first. Only after that succeeds do they uninstall the old `tidewatch` and `mw-watch`. A stub `tidewatch` plugin stays for one release and only tells you to run `mw update --plugins`.
- Alerts show in the pane and as an in-app toast with a ping, never as macOS notification banners. Alert text reads `<job> ▸ <What>: <ref> <title>`.
- The chat-bar status shows per-job segments with zero setup.
- In the pane, news releases are called issues: the "Publish" button, and "Issue N · date · vs issue N-1". The CLI keeps `mw news --release`.
