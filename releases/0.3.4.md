The `tidewatch` plugin is now `mw-watch`, matching `/mw-next` and `/mw-board`.

- Use `/mw-watch` (same subcommands). `/tidewatch` still works as a deprecated alias for one release and prints a one-line hint.
- Your boards, styles and settings are imported from the old plugin on first start; nothing to re-add.
- `install.sh`, `install.ps1` and `mw update` uninstall the old `tidewatch` plugin (best effort, one line: `plugin tidewatch: removed (renamed to mw-watch)`) and install `mw-watch`.
- `/mw-watch` needs no setup: with no boards yet it finds them with `mw boards` (boards this session used first, then the session folder, then `~`). `/mw-watch scan [DIR]` lists boards not added yet (Add / Add all), `/mw-watch add PATH` on a folder without a board scans it, `/mw-watch hide ID TENANT` and the pane's Tenants row hide tenants. An mw without `boards` gets a toast to run `mw update`.
- Fanfare: the pane's Test button is gone; `/mw-fanfare` (state, cycle button, `test|on|off|next|use NAME`) replaces it, and a failed test says why in one line. With no fanfare pair on disk mw plays a built-in WAV. New `mw user fanfare-defaults` (run by `install.sh`, `install.ps1`, `mw update` and `mw update --plugins`) sets `fanfare.enabled=true` and `fanfare.use=all` only where unset; `MW_NO_FANFARE=1` or `MW_NO_PLUGINS=1` skips.
- New plugin `mw-jobs` (`claude plugin install mw-jobs@miniwaves`; `install.sh`, `install.ps1` and `mw update` install it with `mw` and `mw-watch`): live Jobs and News panes (`/mw jobs`, `/mw news`) in the Agile and Kanban layouts (also blocks, gopher and board), detail panels for items and milestones, alert rows on top of the panes, a gopher bar that fills with progress, and a settings pane (`/mw-configure`). It needs no setup: it finds the boards this session used, then the session folder, then `~`. The optional `registry` option (default `~/.mw/jobs.json`, a missing file is normal) lists jobs by hand; per-job logs go in a `logs` folder beside it.
- `mw configure` walks your personal settings (pane, alerts, fanfare, chat bar, discovery) and saves or discards them. `mw user get [KEY] [-j]` lists every key with its value and source.
- mw-watch follows those settings: alerts, discovery and refresh time, including 15s and off. It no longer draws the chat-bar status, which mw-jobs now owns. It finds the session's boards at start.
- `mw boards` finds boards and their tenants. `mw news --full` gives uncapped lists.
