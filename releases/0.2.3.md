Session release and reap; no schema change, no migration.

- `mw session stop NAME -t T --release`: doing items go back to ready (owner cleared, note appended), then the session stops. Without the flag the refusal stays.
- `mw session reap [-t T | -A] [--older-than DUR] [--except NAME,NAME] [-n] [-j]`: releases and stops sessions idle longer than DUR (default 2h); `-j` prints `{"reaped":[...]}`.
- `mw board` shows `doing 3h` per doing item; `mw review` has a STALE section; `session list -v` shows the age.
- Session last activity is refreshed by note and edit as well as start/ready/block/done/reopen.
- Prompts end with "Before you idle: `mw done`, `mw block`, or `mw session stop NAME -t T --release`."
