Self-update fix; no schema change, no migration.

- `mw update` accepts `release-assets.githubusercontent.com`, the host GitHub now redirects release downloads to. Hosts are still matched exactly over https; lookalikes stay refused.
- mw 0.2.5 and older cannot self-update to this release (they refuse the new host). Update once with `install.sh` / `install.ps1` or `claude plugin marketplace update miniwaves && claude plugin update mw@miniwaves`; `mw update` works from 0.2.6 on.
