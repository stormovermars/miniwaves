First working release after 0.1.0 (the v0.2.0 tag never produced release assets). Schema 8, run `mw migrate` (see [MIGRATION.md](../MIGRATION.md) and the 0.2.1 entry in [USAGE.md](../USAGE.md#changelog)).

- `mw next --claim` with an inline prompt, a start guard, `mw archive`.
- Per-tenant storage (schema 8), kernel locks with lockless reads.
- `mw board --html` with a publish interval throttle.
- Prompts of at most 20 lines, Claude plugin, install scripts, CI.
- `mw tenant archive|restore SLUG` hides a tenant everywhere without touching its files; `mw tenant tag SLUG +a -b` and `--tag` filters; tags on the board, the page and `version -j`.
- `mw update [--check]` self-update from GitHub releases; `mw version` prints the releases URL.
- Windows: native support (rename retry over open files, `~\` paths, installer adds mw to PATH, CI gate on windows-latest).
- Git is the agent's job.
