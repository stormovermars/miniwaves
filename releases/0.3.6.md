No schema change, no migration step. After `mw update`, run `mw update --plugins` once to get the mw-jobs changes.

Fanfare (TSK-067)

- mw no longer opens a dialog or notification of its own. The finale Stop dialog (macOS `osascript`, Windows popup, `zenity`, `kdialog`) and the built-in icon file it wrote are gone; sound players are unchanged.
- The `stop_dialog` key is still read, so old boards parse, but it is ignored. `mw fanfare set stop_dialog=...` prints a deprecation note on stderr. Stop a playing fanfare with `mw fanfare stop` or the mw-jobs Stop button.
- `mw fanfare -j` always carries `playing` (count of players mw started that still run) and `playing_finale` (true while one of them is a finale), and `stop_dialog_deprecated: true` only while a board still has the key. `.players.json` entries gain `kind` (`milestone` or `finale`).
- A guard test fails the build if any non-test source or kit script contains `osascript`, `zenity`, `kdialog` or a Windows popup.
