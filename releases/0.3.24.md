No schema change (still 9), no migration step. The new event field is optional.

- `mw ask ID QUESTION --option A --option B`: a closed question with 2 to 4 options (distinct, case-insensitive). `mw answer` accepts only one of the options (and refuses `--accept`), `mw review` shows them as `[A | B]`, and the JSON needs rows and `log -j` carry them. Without `--option` nothing changes.
- An event now keeps JSON fields this mw does not know when the board is saved, as items already did. A computer on an older version no longer drops the `options` of a question; run 0.3.24 on every computer that shares a board, since 0.3.23 and older still drop them.
