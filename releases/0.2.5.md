Gate levels; no schema change, no migration.

- `mw gate level trust|proof|spec|judged [-t SLUG|--workspace]` sets evidence, acceptance and judge cumulatively: trust none, proof evidence, spec + acceptance, judged + judge. Humans only, like the per-gate commands.
- New default is `proof`: evidence is on for every tenant, not only product tenants (boards migrated from schema 5 keep workspace default `off`, so new tenants there start at `trust`). `mw gate level trust` goes back to no gates.
- `mw gate` prints the level first (`level custom` when the three settings match no level); `mw gate -j` prints `{level, gates}` instead of a bare array. The gates line on board, context and next is `gates: proof` when the level has a name.
