Plugin release; mw itself is unchanged since 0.3.1.

- The tidewatch pane plugin is now in the miniwaves marketplace. 0.3.0 documented `claude plugin install tidewatch@miniwaves`, but the plugin was missing from the marketplace, so the install failed. Run `claude plugin marketplace update miniwaves`, then `claude plugin install tidewatch@miniwaves` and `/tidewatch`. It shows `mw jobs` boards, toasts, and the `mw news` pane.
